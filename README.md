# Women Fiber to Fashion

Static website for Women Fiber to Fashion — ethical, women-led garment manufacturing based in New Delhi, India.

Live at https://nkb134.github.io/wf2f/

## Status

Placeholder page deployed. Full site in progress.

## Stack

Plain HTML + CSS, no build step. GitHub Pages serves `main` from the repo root.
Every push to `main` redeploys automatically.
